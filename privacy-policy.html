سياسة الخصوصية وسرية البيانات

توضح هذه الصفحة التزام ونش الحربي بحماية خصوصيتك وبياناتك الشخصية عند استخدام موقعنا الإلكتروني أو الاتصال بنا.

1. البيانات التي نجمعها

عند طلب خدمة ونش أو ملء نموذج الاتصال أو إرسال موقعك عبر واتساب، نجمع فقط المعلومات الضرورية لإتمام عملية الإنقاذ الميداني: اسم العميل، رقم الهاتف للتواصل، نوع وموديل السيارة، والموقع الجغرافي للعطل ونقطة التوصيل.

2. كيفية استخدام البيانات

تُستخدم بياناتك حصرياً لتوجيه أقرب سائق سطحة لموقعك، والتواصل معك لتأكيد وصول الونش وتقديم الخدمة. لا نقوم إطلاقاً ببيع أو تأجير أو مشاركة بياناتك مع أي أطراف ثالثة أو شركات إعلانية.

3. أمان وسرية البيانات

نطبق معايير تقنية مشددة لحماية أي معلومات تصلنا عبر الموقع، ويتم التعامل مع أرقام الهواتف والمواقع بأعلى درجات الأمان والسرية المهنية.

4. التواصل معنا بشأن الخصوصية

إذا كان لديك أي استفسار يتعلق بسياسة الخصوصية، يمكنك التواصل معنا مباشرة عبر الهاتف: 01030185097 أو 01120492880 أو عبر واتساب.
