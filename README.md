# ونش الحربي لإنقاذ وسحب السيارات (Al Harbi Towing) 🚨🏎️

- طريق القاهرة - الإسماعيلية الصحراوي
- طريق القاهرة - السويس الصحراوي
- مدينة الشروق
- مدينتي ومحور الأمل
- مدينة المستقبل ومساكن ضباط المستقبل
- مدينة بدر والمنطقة الصناعية

## 🌟 مميزات المشروع والمنصة

1. **تصميم متجاوب بالكامل (Ultra-Responsive)**: متوافق 100% مع كافة مقاسات الشاشات (الهواتف الذكية، التابلت، الشاشات الكبيرة) بدقة فائقة وبدون أي خروج عن حدود الشاشة.
2. **أصول حقيقية 100% (No AI Images)**: صور واقعية لأسطول سيارات السطحة الهيدروليكية، والعمليات الميدانية، وبوابات المدن، مع مقاطع فيديو حقيقية لعمليات السحب.
3. **تهيئة قصوى لمحركات البحث والخرائط (SEO & Local GEO Schema)**:
   - بيانات منظمة متوافقة مع معايير Schema.org (`EmergencyService`, `BreadcrumbList`).
   - إشارات جغرافية دقيقة (Geo-coordinates & Regions) للعاشر من رمضان والمحاور المحيطة.
   - OpenGraph و Twitter Cards مجهزة بالكامل للمشاركة على منصات التواصل.
4. **تكامل نافذة اختيار الواتساب (Dual-Number WhatsApp Modal)**: وصول مباشر للرقمين بضغطة زر واحدة.

## 🗂️ هيكل صفحات الموقع

- `index.html`: الصفحة الرئيسية، أسطول السيارات، البانر التفاعلي، الفيديوهات الميدانية، وآلية العمل.
- `services.html`: دليل الخدمات التفصيلي (سطحات هيدروليك كاملة النزول، إنقاذ الحوادث، سحب الملاكي والدفع الرباعي، ونش جامبو، إنقاذ غرز الرمال).
- `areas.html`: دليل محاور التغطية الـ 6 والتمركز الميداني بنظام شبكة العرض المزدوجة.
- `pricing.html`: معايير التسعير العادل والشفاف بدون أي إكراميات أو مصاريف خفية.
- `about.html`: نبذة عن ونش الحربي، أسطول العمليات، ومعايير السلامة المهنية.
- `partner.html`: تعاقدات الشركات والمصانع ومراكز الصيانة ومعارض السيارات.
- `blog.html`: إرشادات السلامة والتعامل مع أعطال الطرق السريعة وارتفاع حرارة المحرك.
- `contact.html`: صفحة الاتصال المباشر، أرقام الطوارئ، واستمارة طلب الونش أونلاين.
- `privacy-policy.html`: سياسة الخصوصية وسرية بيانات العملاء والمواقع.
- `thank-you.html`: صفحة تأكيد استلام الطلب وتوجيه السائق لموقع العميل.
